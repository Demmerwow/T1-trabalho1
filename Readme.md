## 📖 Sobre o Projeto

O **Instituto Arkham do Saber (IAS)** é uma instituição educacional fictícia localizada em Gotham City. O site foi desenvolvido como parte do Trabalho 1 da disciplina, com o objetivo de demonstrar o uso correto do **HTML5 semântico**, acessibilidade e boas práticas de código — **sem uso de CSS**, conforme exigido pelo enunciado.

O tema foi inspirado no universo Batman, mas com um tom leve e criativo: o antigo Asilo Arkham foi transformado em um centro educacional moderno, e personagens conhecidos aparecem como professores e pesquisadores legítimos.

---

## 🎯 Objetivos de Aprendizagem Atendidos

- ✅ Estruturar páginas web usando HTML5 semântico
- ✅ Aplicar tags apropriadas para diferentes tipos de conteúdo
- ✅ Criar formulários funcionais com validação HTML5
- ✅ Garantir acessibilidade básica no código HTML
- ✅ Trabalhar colaborativamente usando Git/GitHub

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Demmerwow/T1-trabalho1.git
   
2. Abra a pasta T1-trabalho1/ no VS Code.

3. Abra o arquivo index.html no navegador (duplo clique ou use a extensão Live Server do VS Code).

4. Navegue pelas páginas usando o menu superior.

    Não é necessário instalar nada. O site é 100% HTML5 puro.
